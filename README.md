# WA Design France — Interior Architecture & Renovation Paris

A luxury architectural monograph and landing page for **WA Design France**, specialized in high-end renovation and interior architecture for Haussmannian and contemporary Parisian residences.

## ✨ Highlights

- **Aesthetic Movement**: Quiet Luxury & Architectural Monograph (French limestone, aged oak, limewashed plaster, patinated bronze, 0px border radius, 1px hairlines).
- **Typography Pairing**: `EB Garamond` for display inscriptions and `Plus Jakarta Sans / Hanken Grotesk` for technical metadata and body text.
- **Seamless Inertial Scrolling**: Powered by **Lenis** (`lenis`) for frictionless, fluid scrolling physics.
- **Bilingual Experience (FR / EN)**: Instant client-side language switcher with complete translations across all sections.
- **Interactive Monograph Gallery**:
  - Asymmetric editorial view & Monograph Index table switcher.
  - Project detail modal sheet with full technical specs and artisan guild credits.
- **Studio Ethos & 3-Step Methodology**: Interactive phase explorer (`Écoute`, `Conception`, `Réalisation`) and key metrics ticker.
- **Tactile Material Inspector**: Tactile specimen cards and detailed inspection sheet.
- **Instagram 9-Tile Editorial Grid**: Curated social grid with photo lightbox, directly linked to [@wa.design.france](https://www.instagram.com/wa.design.france/).
- **Consultation Booking Form**: Bespoke inquiry questionnaire with budget and surface chips.

## 🛠️ Tech Stack

- **Framework**: Next.js 15 (App Router, TypeScript)
- **Styling**: Tailwind CSS
- **Smooth Scroll**: Lenis (`lenis`)
- **Animations**: Framer Motion (`framer-motion`)
- **Icons**: Lucide React (`lucide-react`)

## 🚀 Getting Started

First, install dependencies:

```bash
npm install
```

Run the development server:

```bash
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) with your browser.

To build for production:

```bash
npm run build
npm run start
```
